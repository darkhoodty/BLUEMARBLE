# LAN 세계여행 보드게임

Python 표준 라이브러리와 Tkinter만 사용하는 2인 턴제 게임입니다. 두 노트북에 이 폴더 전체를 복사하세요. Python 설치 시 Tcl/Tk를 포함해야 합니다. 별도 pip 설치는 필요 없습니다.

## 실행

```powershell
python main.py
```

1. 두 노트북을 같은 Wi-Fi 또는 유선 LAN에 연결합니다.
2. 첫 번째 노트북에서 **방 만들기**를 누릅니다.
3. 화면에 표시된 호스트 IPv4 주소를 두 번째 노트북에 입력하고 **참가하기**를 누릅니다. 포트는 양쪽 모두 기본 5000입니다.
4. Windows 방화벽 알림이 나오면 신뢰하는 **개인 네트워크**에서 Python 연결을 허용합니다. 인터넷 공유기의 포트 포워딩은 필요 없습니다.
5. 내 차례에 주사위를 굴리고, 도착한 땅을 구매하거나 건물을 지은 다음 **턴 종료**를 누릅니다. 세계여행에서는 보드의 목적지를 클릭한 뒤 여행 버튼을 누릅니다.

접속이 안 되면 `ipconfig`에서 실제 Wi-Fi/이더넷 IPv4를 확인하세요. 게스트 Wi-Fi의 기기 간 통신 차단, VPN, 방화벽, 서로 다른 포트 설정도 확인하세요. 연결이 끊어지면 메뉴로 돌아가 새 방을 만드세요. 재접속과 저장은 지원하지 않습니다.

## 구현 규칙

시판 부루마블의 특정 판본을 그대로 복제한 규칙이 아니라 핵심 구조를 바탕으로 만든 자체 32칸 보드입니다. 모든 금액 단위는 만원입니다.

- 시작 자금 300, 출발 통과/도착 월급 30. 주사위 2개로 이동합니다. 더블 추가 턴은 없습니다.
- 도착한 빈 도시를 구매할 수 있습니다. 자기 도시에서는 별장 → 빌딩 → 호텔 순서로 최대 3단계까지 건설합니다. 같은 턴에 여러 단계 건설도 가능합니다.
- 땅값은 `10 + 칸 번호 × 2`, 단계별 건설비는 `10 + (칸 번호 // 8) × 5`입니다.
- 통행료는 `땅값 // 4`에 대지 1배, 별장 3배, 빌딩 7배, 호텔 14배를 적용합니다.
- 황금열쇠: 보너스 30/50, 수리비 30, 출발 이동+월급, 무인도 이동 중 무작위로 하나를 적용합니다.
- 무인도: 다음 자기 차례 2회를 쉽니다. 주사위 버튼을 누르면 휴식 차례가 처리됩니다.
- 기금 납부 20, 사회복지기금 칸에서는 누적된 기금을 수령합니다.
- 세계여행: 10을 내고 다른 칸을 선택합니다. 여행 이동에는 출발 월급이 없습니다. 여행을 하지 않고 턴을 마쳐도 됩니다.
- 지급액이 부족하면 건물부터, 이후 땅을 절반 가격으로 자동 매각합니다. 그래도 부족하면 남은 현금을 지급하고 파산합니다. 상대가 승리합니다.
- 경매, 담보 대출, 플레이어 간 거래, 도시 독점 보너스는 없습니다.

호스트가 주사위와 경제 상태를 계산하고 참가자는 행동 요청만 보냅니다. Tkinter 화면과 네트워크 스레드를 분리했습니다. 신뢰하는 LAN에서 사용할 목적으로 인증/암호화는 제공하지 않습니다.

## 테스트

```powershell
python -m unittest -v test_network
```
